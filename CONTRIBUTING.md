# Contributing

Thanks for your interest in contributing to Minecraft Server Gameplay Toolkit.

## Good first contributions

- Fix incorrect or unclear documentation.
- Test examples on a supported server version and report your environment.
- Suggest modular features with a clear use case.
- Improve example scripts while keeping them readable.

## Pull request process

1. Open an issue first for substantial new features.
2. Create a focused branch and keep changes small.
3. Explain what changed, why, and how you tested it.
4. For Skript changes, provide your Minecraft server version, Skript version, optional plugin versions, and console output when relevant.
5. Avoid shipping proprietary assets or code without permission.

## Bug report information

Please include steps to reproduce, expected behavior, actual behavior, version numbers, and relevant console messages. Remove secrets and player-identifying data before posting logs.

## Coding principles

- Prefer clear variable names and short, self-contained scripts.
- Document dependencies and commands.
- Keep configurable values together.
- Do not claim a feature is tested unless it was actually tested.
