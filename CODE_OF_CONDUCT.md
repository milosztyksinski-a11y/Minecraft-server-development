# Community Code of Conduct

We welcome constructive feedback and contributions from people with different experience levels. Please be respectful, assume good faith, and focus criticism on ideas and code rather than individuals.

Harassment, threats, discriminatory remarks, and intentional disruption are not acceptable in project discussions. Maintainers may moderate issues, discussions, and contributions to keep collaboration productive.

To report a conduct concern, contact a repository maintainer through GitHub using the available private contact channels.
