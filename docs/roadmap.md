# Roadmap

This is a planning document. The unchecked items are **not completed**.

## Phase 1 — Foundation

- [x] Create repository structure and initial documentation.
- [x] Add a simple example with a reusable cooldown concept.
- [ ] Test and verify the example on specific server/Skript versions.
- [ ] Publish a verified compatibility matrix.

## Phase 2 — Gameplay utilities

- [ ] Customizable PvP abilities and cooldown modules.
- [ ] Per-world or per-region gameplay configuration.
- [ ] Optional WorldGuard integrations.
- [ ] Basic administrative tools and logging.

## Phase 3 — Community maintenance

- [ ] Automated validation where feasible.
- [ ] Contribution-friendly configuration and examples.
- [ ] Localization and more complete tutorials.
- [ ] Release and changelog process tied to verified tests.

Priorities may change based on real development, feedback, and available maintainers.
